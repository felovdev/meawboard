# meaw board

Онлайн-доска в стиле Material Design 3: стикеры, текст, фигуры, стрелки, карандаш, бесконечный холст (масштаб от 2% до 800%), тёмная тема, экспорт в PNG / SVG / JSON.

**Демо:** https://felovdev.github.io/meawboard/

## Два режима

| | Локальный | С сервером |
|---|---|---|
| Как запустить | Открыть `index.html` или сайт на GitHub Pages | `node server.js` → http://localhost:3000 |
| Где лежат доски | В браузере (localStorage) | На сервере, файл `data.json` |
| Несколько досок, переименование, удаление | да | да |
| Регистрация, вход, гостевой режим | — | да |
| Ссылка «Поделиться», совместная работа в реальном времени, курсоры | — | да |

Режим выбирается автоматически: если сервер не отвечает, доска работает локально.

## Запуск сервера

Нужен [Node.js](https://nodejs.org) 18+. Внешних зависимостей нет.

```bash
node server.js          # http://localhost:3000
PORT=8080 node server.js
DATA_FILE=/var/meaw/data.json node server.js
```

Чтобы звать людей из интернета, разместите сервер на хостинге с Node.js (Render, Railway, Fly.io, VPS) — GitHub Pages для этого не подходит, там нет серверной части.

## Управление

| | |
|---|---|
| Двойной клик по пустому месту | новый стикер |
| Колесо мыши / щипок | масштаб |
| Два пальца на трекпаде, стрелки, Пробел + перетаскивание, колесо мыши нажатой | перемещение |
| `V` `H` `N` `T` `R` `O` `D` `A` `P` `E` | выбор, рука, стикер, текст, прямоугольник, овал, ромб, стрелка, карандаш, ластик |
| `Ctrl+Z` / `Ctrl+Y` | отменить / повторить |
| `Ctrl+C` `Ctrl+V` `Ctrl+D` `Ctrl+A` | копировать, вставить, дублировать, выделить всё |
| `0` / `1` / `+` / `-` | показать всё / 100% / приблизить / отдалить |

## Файлы

- `index.html`, `style.css`, `script.js` — сама доска (холст, инструменты, история).
- `app.js` — аккаунты, список досок, «Поделиться», синхронизация, локальный режим.
- `server.js` — сервер без зависимостей: аккаунты (scrypt), сессии, доски, синхронизация через SSE.
