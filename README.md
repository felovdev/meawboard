# meaw board
Онлайн-доска в стиле Material Design 3: бесконечный холст, стикеры, фигуры, рисунок, стрелки, картинки (вставка, обрезка, фильтры, поворот), главная со списком досок, приватные доски и доступ по ссылке, совместная работа с курсорами. Облако — Firebase (см. SETUP.md), без него — демо-режим в браузере.
